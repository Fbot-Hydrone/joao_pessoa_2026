## Commit 1 — `6687bb1f` Stop tracking colcon build artifacts; add .gitignore

The bulk of this commit was a mass `git rm -r --cached` of the `build/`,
`install/`, and `log/` directories (thousands of generated files). Those should
never have been committed: they bake in machine-specific absolute paths and
break builds on other machines. The only hand-written content was a new
`.gitignore`.

### To redo

Add `.gitignore` at the repo root:

```gitignore
# colcon build artifacts (regenerated by `colcon build`; never commit these —
# they bake in machine-specific absolute paths and break builds elsewhere)
build/
install/
log/
```

Then stop tracking anything already committed under those dirs:

```bash
git rm -r --cached build install log
git add .gitignore
git commit -m "Stop tracking colcon build artifacts; add .gitignore"
```

## Commit 2 — `14403711` Dockerfile: skip gradle submodulesUpdate task

Micro-XRCE-DDS-Gen's `thirdparty/` sources are vendored as plain files and there
is no `.git` in the build context (excluded by `.dockerignore`), so the
git-based `submodulesUpdate` gradle task failed. Skip it with
`-x submodulesUpdate`.

> Note: this is directly relevant to the `Could not find the program
> ['microxrceddsgen']` failure seen when building `ardupilot_sitl` — that
> program is produced by this gradle build.
